# Решись Авиа

Начальная версия приложения на Next.js. Интерфейс перенесён из проекта Wanderlust Travel и будет адаптирован к задаче расчёта спроса на авиаперевозки.

## Запуск

```bash
npm ci
npm run dev
```

Откройте http://localhost:3000. Проверка доступности сервера: `GET /api/health`. Форма исходного сайта временно отключена и не отправляет заявки.

Для production-сборки выполните `npm run build`, затем `npm start`.
