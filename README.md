# Решись Авиа

Приложение на Next.js для будущего расчёта спроса на авиарейсы. Доступен интерфейс на русском и английском языках с выбором направления, даты и цены билета. Расчёт, вход и регистрация пока не подключены; результаты и график появятся после реализации расчёта.

## Запуск

```bash
npm ci
npm run dev
```

Откройте http://localhost:3000. Проверка доступности сервера: `GET /api/health`. Устаревший `POST /api/lead` отключён и возвращает 503.

Для production-сборки выполните `npm run build`, затем `npm start`.
