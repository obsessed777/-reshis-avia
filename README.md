# Решись Авиа

Веб-приложение для менеджера авиакомпании: оценка спроса, продаж и свободных мест по маршруту, дате и цене билета. Расчёт открыт без входа; доступны регистрация и вход по email и паролю. Интерфейс работает на русском и английском языках. Покупка и бронирование билетов не предусмотрены.

## Проверка расчёта

Выберите маршрут из Москвы, дату и цену, затем нажмите кнопку расчёта. Поддерживаются MOW–AER, MOW–KGD, MOW–LED, MOW–MRV и MOW–OVB с 1 июня по 1 июля 2026 года включительно: 155 сочетаний маршрута и даты. Например, MOW–AER, 2026-06-01, 9000 ₽: вместимость 900, спрос и продажи 845, свободно 55 мест.

Для каждого квантиля q от 0,1 до 0,9 спрос равен `q_base_demand - price_sensitivity * (price - base_price)`. Основной спрос соответствует медиане q = 0,5; продажи равны `min(seats, max(0, demand))`, свободные места — `seats - sales`. График показывает девять квантилей и вместимость. Это прогноз, а не гарантированный результат; хвосты распределения за пределами 0,1–0,9 неизвестны. Цена должна быть положительным конечным числом не более чем с двумя знаками после запятой; диапазон маршрута рекомендательный.

Исходные CSV находятся в `data/`. Перед запуском и сборкой они проверяются и преобразуются в серверный набор данных; обучение модели при расчёте не запускается.

## Локальный запуск

Установите Node.js 22.18 или новее и зависимости, затем запустите приложение:

```bash
npm ci
npm run dev
```

Откройте http://localhost:3000. Для авторизации создайте `.env.local` с переменными `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY` и `APP_ORIGIN` (локально `http://localhost:3000`). Значения URL и publishable key возьмите из своего проекта Supabase; файлы окружения не следует публиковать. В Supabase Auth включите вход по email и паролю и отключите Confirm email для регистрации без письма. Собственные таблицы и service role key не нужны. Без настроенного Supabase расчёт остаётся доступным, авторизация не работает.

```bash
npm run build
npm test
npm run lint
npx tsc --noEmit
npm start
```

## Размещение

Приложение рассчитано на Vercel и Cloudflare Workers через OpenNext. На каждом хостинге задайте `SUPABASE_URL`, `SUPABASE_PUBLISHABLE_KEY` и `APP_ORIGIN` с origin именно этого размещения; оба могут использовать один проект Supabase. Для Vercel используется стандартная сборка `npm run build`. Для Cloudflare доступны `npm run worker:build`, `npm run worker:preview` и `npm run worker:deploy` после настройки аккаунта и окружения.

На [Vercel](https://reshis-avia-taupe.vercel.app/) пока опубликована предыдущая оболочка; новая версия с расчётом и авторизацией ожидает публикации и проверки на обоих хостингах.
